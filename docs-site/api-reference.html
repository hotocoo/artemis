API Reference

CLI Commands

artemis scan

Run a security assessment on a project or directory.

artemis scan [path] [options]

Options:
  --severity <level>    Filter findings by minimum severity (low|medium|high|critical)
  --report <format>     Output format(s), comma-separated (sarif|json|html|text|sbom)
  --output <path>       Output file or directory path
  --config <path>       Path to custom configuration file
  --scanners <list>     Comma-separated list of scanners to run
  --verbose             Enable verbose output
  --quiet               Suppress non-error output
  --timeout <seconds>   Maximum scan duration

artemis config

Manage Artemis configuration.

artemis config --list              # List all configuration options
artemis config --get <key>         # Get a specific configuration value
artemis config --set <key> <val>   # Set a configuration value

artemis audit

Manage the audit ledger.

artemis audit --verify             # Verify audit ledger integrity
artemis audit --export <path>      # Export audit log to file

Configuration Schema

{
  "scanners": {
    "secrets": { "enabled": true, "patterns": [] },
    "dependencies": { "enabled": true, "ecosystems": [] },
    "lint": { "enabled": true, "rules": [] },
    "sast": { "enabled": true, "languages": [] },
    "sbom": { "enabled": true, "format": "cyclonedx" }
  },
  "severity": "medium",
  "report": {
    "formats": ["json"],
    "output": "./reports",
    "includeDetails": true
  },
  "audit": {
    "enabled": true,
    "path": "./artemis-audit.db"
  }
}

Output Formats

SARIF 2.1

Standard format for static analysis results, compatible with GitHub CodeQL, GitLab, and other CI/CD platforms.

JSON

Machine-readable format with full finding details.

HTML

Human-readable report with severity badges and filtering.

CycloneDX SBOM

Software Bill of Materials in CycloneDX format for dependency tracking.

Exit Codes

  • 0 - No findings or all findings below severity threshold
  • 1 - Findings detected at or above severity threshold
  • 2 - Configuration or runtime error
