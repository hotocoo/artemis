Artemis

Autonomous Defensive Security Assessment Platform

Artemis is a .NET 10 security tool that autonomously assesses codebases for security vulnerabilities, dependency risks, and configuration issues. It provides actionable findings with severity ratings, remediation guidance, and comprehensive reporting in multiple formats.

Get Started See Examples

Key Features

🔍 Multi-Scanner Architecture

18 specialized scanners covering secrets, dependencies, linting, SAST, SBOM, and more.

📊 Comprehensive Reporting

Export findings in SARIF 2.1, CycloneDX SBOM, JSON, HTML, and text formats.

🔒 Fail-Closed Design

Deterministic, reproducible results with hash-chained audit ledger for compliance.

⚡ Enterprise Performance

Built-in benchmarks and performance regression tracking for large codebases.

🛡️ Property-Based Testing

17 FsCheck property-based tests ensuring mathematical correctness of core algorithms.

📦 NuGet Distribution

Easy installation via NuGet with global tool support.

Quick Start

# Install as a global tool
dotnet tool install -g artemis

# Run a full assessment
artemis scan /path/to/your/project

# Generate SARIF report for CI/CD
artemis scan /path/to/project --report sarif -o findings.sarif
