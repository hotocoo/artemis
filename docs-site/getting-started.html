Getting Started

Installation

As a Global Tool

dotnet tool install -g artemis

From Source

git clone https://github.com/acotech/Artemis.git
cd Artemis
dotnet build -c Release
dotnet run --project src/ACT.Desktop -- --help

Requirements

  • .NET 10 SDK or later
  • Git (for repository analysis)

Basic Usage

# Scan a project
artemis scan /path/to/project

# Scan with specific severity filter
artemis scan /path/to/project --severity high

# Generate multiple report formats
artemis scan /path/to/project --report sarif,json,html -o reports/

Command Reference

artemis scan [path] [options]
  --severity <level>    Filter by severity (low|medium|high|critical)
  --report <format>     Output format (sarif|json|html|text|sbom)
  --output <path>       Output file/directory
  --config <path>       Custom configuration file
  --verbose             Enable verbose output

artemis config [options]
  --list                List all configuration options
  --get <key>           Get a configuration value
  --set <key> <value>   Set a configuration value

artemis audit
  --verify              Verify audit ledger integrity
  --export <path>       Export audit log

Configuration

Artemis uses a JSON configuration file (artemis.json) that can be placed in the project root or specified with --config.

{
  "scanners": {
    "secrets": { "enabled": true },
    "dependencies": { "enabled": true },
    "lint": { "enabled": true },
    "sast": { "enabled": true }
  },
  "severity": "medium",
  "report": {
    "formats": ["json", "sarif"],
    "output": "./reports"
  }
}

CI/CD Integration

GitHub Actions

name: Security Scan
on: [push, pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '10.0.x'
      - run: dotnet tool install -g artemis
      - run: artemis scan . --report sarif -o findings.sarif
      - uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: findings.sarif

GitLab CI

security-scan:
  stage: test
  script:
    - dotnet tool install -g artemis
    - artemis scan . --report sarif -o findings.sarif
  artifacts:
    reports:
      sarif: findings.sarif
