Architecture

Overview

Artemis follows a modular, plugin-based architecture with 18 specialized assessment modules (ACT.*). Each module is independently testable, benchmarked, and versioned.

Module Map

artemis (CLI)
├── ACT.Core              # Core abstractions and interfaces
├── ACT.Configuration     # Configuration management
├── ACT.Logging           # Structured logging
├── ACT.Persistence       # Storage and audit ledger
├── ACT.Reporting         # Report generation
├── ACT.Sandbox           # Execution sandboxing
├── ACT.Orchestration     # Pipeline orchestration
│
├── ACT.SourceAnalysis    # Source code parsing
├── ACT.DependencyAnalysis # Dependency graph analysis
├── ACT.Lint              # Code linting
├── ACT.Sast              # Static application security testing
├── ACT.Secrets           # Secret detection
├── ACT.Sbom              # Software Bill of Materials
├── ACT.Scope             # Scope evaluation (IP/CIDR)
├── ACT.Dns               # DNS analysis
├── ACT.Tls               # TLS certificate analysis
├── ACT.Network           # Network configuration analysis
├── ACT.Container         # Container image analysis
├── ACT.Kubernetes        # Kubernetes manifest analysis
├── ACT.Cloud             # Cloud configuration analysis
├── ACT.Iam               # Identity and access management
├── ACT.Database          # Database schema analysis
├── ACT.CiCd              # CI/CD pipeline analysis
└── ACT.Audit             # Audit and compliance

Design Principles

  • Fail-Closed: All parsers and evaluators fail closed on unexpected input rather than guessing.
  • Deterministic: Results are reproducible given the same input and configuration.
  • Hash-Chained Audit: All findings are recorded in a tamper-evident audit ledger.
  • Typed Contracts: Frozen typed contracts between modules ensure compatibility.
  • Property-Based Testing: Core algorithms verified with FsCheck property-based tests.

Data Flow

Input (path/config) → Configuration → Orchestration
                                    ↓
                    Source Analysis → Lint → SAST → Secrets → Dependencies
                                    ↓
                    Scope → DNS → TLS → Network → Container → Kubernetes
                                    ↓
                    Cloud → IAM → Database → CI/CD → SBOM
                                    ↓
                                Reporting
                                    ↓
                    SARIF | JSON | HTML | Text | SBOM

Technology Stack

  • Language: C# (.NET 10)
  • Testing: xUnit + FsCheck (property-based) + BenchmarkDotNet
  • Reporting: SARIF 2.1, CycloneDX SBOM, JSON, HTML, Text
  • Persistence: SQLite (audit ledger)
  • Distribution: NuGet global tool
